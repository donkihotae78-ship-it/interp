대면 통역 PWA (IT-SPEC-001) — 설치·사용
작성 2026-10-21

[구성]
public/index.html          앱 본체 (화면·통역·기록·요약)
public/manifest.webmanifest 홈 화면 설치 정보
public/sw.js               앱 화면 캐시 (API 호출은 캐시 안 함)
public/icon-192/512.png    아이콘

[1. 배포 — GitHub Pages, 1회]
1) GitHub에서 새 저장소 생성 (예: interp), Public
2) public 폴더 안 파일 5개를 저장소 최상단에 업로드
3) Settings → Pages → Branch: main / (root) → Save
4) 1~2분 후 https://<계정>.github.io/interp/ 접속

[2. 휴대폰 설치]
- 아이폰: 사파리로 접속 → 공유 → 홈 화면에 추가
- 안드로이드: 크롬으로 접속 → 메뉴 → 앱 설치
- 첫 실행 시 마이크 권한 허용

[3. 최초 설정 (⚙)]
- OpenAI API 키 입력 → 이 휴대폰 내부에만 저장, 서버 없음
- 상대 언어: 중국어 / 영어
- 모드: 자동(기본) / 버튼(소음 환경)
- 용어집: 한 줄에 "한국어=상대언어" → 하단 용어 카드 생성
- OpenAI 대시보드에서 월 사용 한도(Usage limit) 반드시 설정

[4. 사용]
- 시작 → 휴대폰을 테이블 중앙에 놓음
- 위쪽 절반: 상대방용(뒤집힌 화면) / 아래쪽 절반: 본인용
- 자동 모드: 그냥 대화. 한국어는 상대 언어로, 상대 언어는 한국어로 음성+자막 출력
- 버튼 모드: 말하는 사람이 해당 버튼을 누르는 동안만 인식
- 🔊 끄면 자막만 (조용한 회의)
- 용어 카드 탭 → 상대 쪽으로 크게 표시, 화면 탭하면 닫힘
- 무음 3분(설정 변경 가능) 시 자동 종료 → 요금 절감
- 기록 → TXT 저장 / 요약·액션아이템 / 기록 삭제(보관함 이동, 최근 30건)

[5. 중국 현지 필수 조건]
- 한국 통신사 로밍 또는 로밍형 eSIM 데이터 사용
- 중국 현지 유심·호텔 와이파이에서는 접속 불가 가능성 높음
- 출국 전 한국에서 1회 실행해 동작 확인

[6. 한계]
- 통역 모델은 용어집 주입 미지원 → 전문용어는 용어 카드로 보완
- 휴대폰 마이크 1개 → 2명 동시 발화 시 인식 실패. 번갈아 말할 것
- 자동 모드는 세션 2개 동시 연결 → 요금 2배 구조. 요금 단가는 OpenAI 가격 페이지 확인
- 요약 모델명(기본 gpt-5.4-mini)은 설정에서 변경 가능
- 기록은 휴대폰 브라우저 저장소 → 앱 삭제·사이트 데이터 삭제 시 소멸. 중요 미팅은 즉시 TXT 저장
